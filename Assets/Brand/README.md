# Markenassets

`timber-beaver.jpg` ist die unveränderte, vom Nutzer am 19.10.2026 bereitgestellte
Vorlage (Datei 19053.jpg). Sie bleibt als historische Gestaltungsreferenz erhalten.

`timber-icon.png` ist das am 21.10.2026 auf Nutzerwunsch neu generierte Biber-Motiv:
Goldener Forsthelm, vereinfachter Waldhintergrund und keine eingebrannte Schrift.
Es wird für App-Symbol, Startintro und Willkommen verwendet. Die Spieltitel bleiben
scharfe Godot-Texte. Alle Bildansichten behalten das Seitenverhältnis.

Der animierte Biber unter `Components/Beaver.gd` ist weiterhin ein eigenes
vereinfachtes Geometriemodell. Das PNG ist kein neues 3D-Figurenmodell.
